# ssdpservice
Accepts SSDP discovery packets and answers with the url for the service xml from a fritzbox
the aim was to make a fritzbox discoverable for devolo powerline adapters even if the powerline adapters are in another subnet than the fritzbox
by doing that the develo powerline adapters can receive the frequence map from dsl in order to adjust their own spectrum
devolo describes this mechanism here: https://github.com/devolo/vdsl-performer-documentation
